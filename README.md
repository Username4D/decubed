# Decubed

Decubed is a platformer webgame made in godot. In the game you control a cube, trying to complete 40 unique levels without dying. The game also contains a speedrun mode challenging the player to beat it as fast as possible. The 40 levels are split into 4 chapters, each with unique themes and objects.

## Editing:

Decubed was made using godot 4.7.1.stable and should be edited using that version. There is no guarantee for it to work in other versions. Levels can be added by creating inhereted scenes of the "level_base" scene, and putting them into the levels folder. Each level uses a color palette, which can be added by editing the "ColorPalettes" global.

## Dependencies:

The game requires the crazygames sdk which can be downloaded from the godot asset store. It uses version 1.0.2 of the sdk, older versions or versions from the asset library are untested and might be incompatible.

## Playing the game:

Since this game is planned to possibly release on crazygames, there is currently no other web host planned for the game. You can however play it yourself if you want to, by downloading and opening the project in godot, adding and enabling the crazygames extension, and testing the game in your browser, using godots web deploy feature.
